## ✨ Create without complexity

Brendy CMS brings pages, articles, media, navigation and editorial workflows together in a single content management system. Build a professional web presence and retain control of your content on your own hosting.

## Explore the possibilities

| 📝 Content | 🎨 Design | 🛡️ Control |

| Rich text editing | Responsive layouts | Backup and recovery tools |
| Media and galleries | Extensible features | Self-hosted content storage |

## Built for your website

- **Publish with confidence:** organize content, categories, tags and menus.
- **Make it yours:** choose from Alternativa, Blog, Fokus, Novosti and Okus.
- **Reach your audience:** manage SEO metadata, sitemaps and search.
- **Extend your experience:** nine included extensions for content, navigation, search, media and more.

## Your content belongs to you

Brendy CMS uses file-based content storage, with no separate SQL database required. Host it on a compatible PHP server and manage your website in one place.
