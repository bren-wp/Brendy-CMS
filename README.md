## Own your content

Brendy CMS stores content in files on your own hosting. **No MySQL, MariaDB or separate database server is required.** Keep your website, content and media together, and use a compatible PHP host of your choice.

- **Self-hosted:** manage your website on your own hosting.
- **Flat-file:** content is stored in JSON-backed files and page documents.
- **Local editing:** the included visual editor can operate without a cloud editor account.
- **Responsive:** included themes adapt to different screen sizes.
